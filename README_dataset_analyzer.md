 # Инструмент анализа качества датасета для проекта сельхоз-запчастей

## Описание

Этот инструмент анализирует качество датасета изображений сельхоз-запчастей перед извлечением эмбеддингов. Он помогает:

- Найти дубликаты изображений
- Оценить качество изображений (размытость, экспозиция, контраст)
- Определить проблемные каталоги
- Выявить изображения с плохим фоном
- Обнаружить потенциально смешанные категории

## Файлы проекта

- `analyze_dataset_simple.py` - основной инструмент анализа датасета
- `dataset_analysis_report.txt` - файл с результатами анализа (создается автоматически)

## Установка зависимостей

```bash
pip install opencv-python-headless pillow numpy pandas tqdm
```

Для полной версии с YOLO-анализом также потребуется:
```bash
pip install ultralytics
```

## Структура датасета

Инструмент ожидает следующую структуру каталогов:

```
data/raw/
├── part001/
│   ├── image1.jpg
│   ├── image2.jpg
│   └── ...
├── part002/
│   ├── image1.jpg
│   ├── image2.jpg
│   └── ...
└── ...
```

Каждый подкаталог соответствует ID детали в базе данных.

## Использование

### Простой анализ:
```bash
python analyze_dataset.py --raw data/raw
```

### С указанием файла отчета:
```bash
python analyze_dataset.py --raw data/raw --output my_analysis_report.txt
```

## Функциональность инструмента

### 1. Поиск дубликатов
- Точные дубликаты (одинаковые хэши MD5)
- Похожие изображения (perceptual hash)

### 2. Оценка качества изображений
- **Размытость**: Оценка по дисперсии оператора Лапласа
- **Контраст**: Стандартное отклонение градиента
- **Экспозиция**: Доля пересвеченных пикселей
- **Яркость**: Средняя яркость изображения
- **Насыщенность**: Средняя насыщенность HSV
- **Детализация**: Соотношение краев (edge ratio)

### 3. Определение проблемных каталогов
- Каталоги с избыточными дубликатами (>50% дубликатов)
- Каталоги с малым количеством изображений (<3)
- Каталоги с низким успехом анализа

### 4. Определение изображений низкого качества
- Слишком размытые изображения
- Изображения с низким контрастом
- Пересвеченные изображения
- Однородные изображения (мало деталей)

### 5. Анализ проблем с фоном
- Слияние фона и детали (низкий контраст)
- Равномерный фон (мало краев)
- Фон занимает слишком большую часть изображения

### 6. Обнаружение потенциально смешанных категорий
- Каталоги с высокой вариативностью характеристик изображений

## Результаты анализа

Инструмент генерирует подробный отчет, включающий:

1. Общую статистику датасета
2. Количество дубликатов
3. Проблемные каталоги
4. Изображения низкого качества
5. Изображения с проблемами фона
6. Рекомендации по улучшению датасета

## Рекомендации по улучшению датасета

- Удалить точные дубликаты из датасета
- Рассмотреть удаление похожих изображений (>95% схожести)
- Проверить и, возможно, удалить проблемные каталоги
- Удалить изображения низкого качества (размытые, темные, пересвеченные)
- Улучшить фон на проблемных изображениях или удалить их
- Использовать разнообразные ракурсы для каждой детали
- Обеспечить равномерное освещение без бликов
- Сделать деталь центральным элементом изображения
- Поддерживать разрешение не менее 300x300 пикселей
- Использовать однородный фон, контрастирующий с деталью

## Влияние на точность нейросети

Анализ и очистка датасета помогут:

- Повысить качество эмбеддингов за счет более чистых изображений
- Уменьшить переобучение на дубликатах
- Улучшить обобщающую способность модели
- Сократить время обучения за счет более чистых данных
- Повысить стабильность и точность распознавания
